СВІТЛО Є? КИЇВ — стартова версія

Що вже працює:
- /start і меню Telegram;
- додавання та збереження кількох адрес;
- перегляд збережених адрес;
- кнопка переходу до офіційного графіка ДТЕК Київські електромережі.

Що ще НЕ підключено:
- автоматичне зчитування графіків ДТЕК;
- автоматичне визначення фактичного зникнення/відновлення світла;
- push-сповіщення про зміни.

Ми не вигадуємо години й не заявляємо про статус світла без підтвердженого джерела.

Безпека:
- НЕ вставляйте токен у bot.py, README або публічний репозиторій.
- Додайте токен на хостингу як секретну змінну середовища BOT_TOKEN.
- Якщо токен випадково опублікували — відкличте його через @BotFather командою /revoke.

Запуск локально:
1. Встановити Python 3.11 або новіший.
2. У папці проєкту виконати: pip install -r requirements.txt
3. Встановити змінну середовища BOT_TOKEN (не передавати її нікому).
4. Запустити: python bot.py

Для цілодобової роботи потрібен хостинг worker-процесу та постійне сховище.
render.yaml — шаблон для Render; потрібен платний Worker і persistent disk.
